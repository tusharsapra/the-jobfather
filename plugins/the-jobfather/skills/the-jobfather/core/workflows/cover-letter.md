# Cover letters

Use the saved JD analysis and 1-2 relevant proof points. Default 150-200 words in natural
paragraphs: why this role fits, the evidence, a short close. Explicit instructions override the
default. Count with `check_text.py`.

Lead with the claim that best matches the role's main requirement (from the analysis), then one
supporting example from a different part of their experience if it helps. Keep metric scope and
the user's share of credit. Do not retell the CV, invent product use, company history, personal
connections or praise. JD context is enough; research only what the user asks for.

Draft → one editorial pass (`references/WRITING-RULES.md`) → humanizer checklist → VOICE.md →
`check_text.py`. Return the letter ready to use; save it with its evidence IDs (workspace.md). A
cover-letter PDF is a separate request and never uses the CV page.
