# LinkedIn messages and notes

Work out the recipient's role, the relationship and the purpose from what the user supplied.

- Cold outreach: a brief, real reason to contact and one clear ask.
- Warm replies: build on the existing exchange; skip the biography.
- Referral requests need a real, supplied relationship; never invent prior contact.
- Share the portfolio or CV link from identity.json when it helps. Never claim an attachment that
  is not being sent.
- Match the reader: a recruiter wants fit and logistics; a hiring manager wants the work.
- Connection notes: use the field limit the user gives, or check the current one; do not assume a
  universal limit. Count with `check_text.py`, spaces included when the field counts them.

Save as a `linkedin` output in the application (workspace.md). Never send. Messaging tools on
LinkedIn are blocked by default; the user sends it themselves.
