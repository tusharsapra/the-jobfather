# Humanize a draft

Read VOICE.md, LEARNED.md and the draft. Keep every fact, number, name, qualifier, intent and
attribution; keep metric definitions and periods. Read supporting EXPERIENCE only if a fact's
meaning is unclear.

Make one focused edit for directness, familiar words and natural rhythm, using
`references/WRITING-RULES.md` and the checklist in `third_party/humanizer/HUMANIZER.md`. The user's
VOICE.md wins over both. No new anecdotes, deliberate typos, invented evidence or claims about AI
detectors. Run `check_text.py` against real limits. Return only the final text unless an
explanation is asked for or a factual problem needs a question. A rewrite is not a new fact or a
saved preference; save the draft with workspace.md or drafts.py.
